Có game HTML5? Đưa nó lên Game Hub

Game của bạn chạy trong khung cách ly, nhận sẵn đăng nhập, bảng xếp hạng và ngôn ngữ của người chơi qua SDK nhỏ gọn. Hỗ trợ cả bản build Unity WebGL.

Mở trang Developer → Đọc tài liệu SDK 
// 1 script tag + 3 calls
await GameHub.init();
GameHub.gameStart();       // round starts
GameHub.gameOver(score);   // submit score

  1. Tạo studio

    Kết nối ví, đặt tên studio, đồng ý điều khoản cho người đăng game. Mời thêm đồng đội bằng địa chỉ ví.

  2. Upload file .zip

    Tối đa 50MB, có index.html. Hub kiểm tra, giải nén và cho bạn chơi thử ngay, xem nhật ký SDK.

  3. Được duyệt và lên hub

    Admin chơi thử rồi duyệt. Game xuất hiện ở trang chủ với bảng xếp hạng riêng.
